ByteBridge is one application for industrial protocols: IEC 60870-5-104, Modbus TCP, DNP3,
OPC UA, OPC DA (classic, Windows), OPC XML-DA and Siemens S7. Every protocol uses the same screens: the same endpoint
editor, the same live data table and the same way to send a command.

<CardGrid>
  <Card title="Tester" icon="laptop">
    The desktop app. Read a real device as a client, or play the device's part as a server
    towards a SCADA system under test.
  </Card>
  <Card title="Gateway" icon="setting">
    A headless Windows service with a web UI. It maps data between protocols and runs unattended.
  </Card>
  <Card title="Central" icon="star">
    Follows many gateways over MQTT (Sparkplug B), deploys signed configurations and audits every change.
  </Card>
  <Card title="Same configuration" icon="random">
    What you build while testing is already the gateway's configuration. Nothing to rebuild.
  </Card>
</CardGrid>
