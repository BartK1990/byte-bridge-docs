Gateway on a PLC

No extra box in the cabinet. The ByteBridge runtime is light enough to run as a Docker container on a controller such as the WAGO PFC200, right next to the PLC program.

  • Native runtime for ARM and x64 Linux, packaged as a container
  • The PLC keeps controlling; ByteBridge handles the communication
  • The web interface runs elsewhere and connects to the runtime remotely
  • Join a central later without changing the setup
