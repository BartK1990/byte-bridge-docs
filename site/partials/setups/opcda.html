Classic OPC DA, made modern

Many plants still run DCS, PLC or SCADA servers that offer only classic OPC DA, which is tied to Windows and DCOM. Install a gateway on the PC that hosts the DA server: it reads the items locally and passes them on through the protocols today's systems expect.

  • Local COM on the same PC: no DCOM settings across the network, no port 135 in the firewall
  • Browse the server's items or list them; subscription with update rate and deadband, or read polling
  • Republish them through the gateway's OPC UA server, with security policies and certificates, or as IEC 104, Modbus, REST or MQTT
  • Report to Central over one outbound, encrypted link that buffers while offline
  • Writes from SCADA or Central go back to the DA item, checked against its type
  • No OPC wrapper or third-party SDK to buy

OPC DA 2.0x client, Windows gateways only. The DA server must be registered as a local (EXE) server, with the OPC Core Components installed, as its setup usually does.
