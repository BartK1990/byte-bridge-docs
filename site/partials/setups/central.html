Central for many sites

Gateways at every site report to one central. See which are online, follow live values, send commands and roll out configuration changes, all from a browser.

  • Live state and values of every gateway and endpoint
  • Edit a site's configuration with the same editors, deploy it signed, roll back in one click
  • Built-in certificate authority: add a gateway with a one-time token
  • Gateways buffer values while the link is down and catch up afterwards
  • Viewer, Engineer, Operator and Admin roles, single sign-on, full audit log
  • Runs as a Docker image
